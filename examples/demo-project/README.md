# Shelf

Shelf is a small command-line tool that keeps track of books lent to friends.
It works offline and keeps every loan in one local file.

## Goals

- Lending a book takes one command and less than ten seconds.
- Every loan records who borrowed the book and when it is due back.

## Constraints

- No account and no server: the data never leaves the computer.
- The data file stays human-readable, so it outlives the tool.

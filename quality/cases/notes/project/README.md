# Lieferplan

Lieferplan plant die Touren eines kleinen Getränkehandels.

## Wie wir arbeiten
Die Fahrer bekommen ihre Touren am Vorabend als PDF.
We decided to plan tours per weekday instead of per order, because the drivers know their regions.
Wir haben entschieden, die Kundendaten nur lokal auf dem Büro-PC zu speichern.

## Ideen
- Vielleicht später eine App für die Fahrer.
- Could we import orders from the web shop?
